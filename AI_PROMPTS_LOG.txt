=============================================
NOTES ON AI TOOL USAGE
=============================================

HOW CHATGPT WAS USED:
ChatGPT was used as a "prompt engineer" layer — I would describe what I needed in plain language and ask ChatGPT to help me write a precise, structured prompt that Antigravity could execute without ambiguity. This two-layer approach (ChatGPT → Antigravity) reduced back-and-forth and made each Antigravity session more focused.

HOW CLAUDE WAS USED:
Claude was used for spot-checking specific logic questions — for example, verifying whether a CSS sticky layout approach was correct, or whether a particular focus-trap implementation pattern was reliable across browsers.

HOW ANTIGRAVITY WAS USED:
Antigravity IDE was the primary execution agent. It had access to the file system, browser, and terminal. It generated all React JSX and CSS code, created components, ran commands, and inspected the running application in the browser. Every section of the project was implemented by Antigravity based on the structured prompts above.

THE WORKFLOW IN PRACTICE:
1. I reviewed the assignment PDF manually.
2. I used ChatGPT to help me write high-quality system prompts and phase prompts.
3. I sent those prompts to Antigravity IDE.
4. Antigravity generated code and I reviewed it visually in the browser.
5. I sent correction prompts (often directly, sometimes via ChatGPT) when something did not match.
6. This loop continued until each section was visually and behaviorally correct.
